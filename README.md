# PorkDetector

Small Minecraft plugin built with Java and the Spigot API.

When a player consumes pork, the plugin reacts with a custom in-game event.

---

## Compatibility

- Minecraft 1.21.1
- Spigot 1.21.1
- Java 21
- Maven

---

## Features

- Detects raw and cooked pork consumption
- Triggers a lightning strike
- Starts a thunderstorm
- Sends a custom player message

---

## Build

mvn clean package
